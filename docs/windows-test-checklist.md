# Windows 真机测试清单（约 10 分钟）

自动化测试只能覆盖规则和界面，下面这些必须在 Windows 真机上走一遍。每发一个涉及 Windows 的版本测一次，把结果（✅ / ❌ + 截图）发给维护者。

准备：一台 Windows 10/11 电脑、耳机、一个能入会的会议软件（Teams / Zoom / 腾讯会议任一）。记下：有没有 NVIDIA 显卡（型号）、内存大小。

## 1. 安装（2 分钟）

- [ ] 双击 `MirrorVoice-x.y.z-windows-x64-setup.exe`，SmartScreen 提示时点“更多信息 → 仍要运行”
- [ ] 安装完成后桌面和开始菜单出现“镜声”，打开后任务栏显示“镜声”图标（不是 Python）

## 2. 设置向导（3 分钟，下载可在后台继续）

- [ ] “下载模型”页自动开始，能看到总进度、速度和剩余时间，单个模型标题后面显示“来源 ModelScope / HuggingFace”
- [ ] 断网再联网后点“重试”，进度从中断处继续（不从 0 开始）
- [ ] “虚拟声卡”页安装 VB-CABLE：弹出管理员确认，装完后状态变为已安装（可能需要重启电脑）
- [ ] 有 NVIDIA 显卡（RTX 30 系及以上）：安装 GPU 音色包能完成；没有：提示用 CPU 克隆音色，录音色要选“用英文朗读”
- [ ] 录音色：模型没下完就点“保存”会提示等待，下完后自动识别文字

## 3. 声音设备与测试链路（2 分钟）

- [ ] 控制面板“声音设备”里，“送进会议”第一项是 `CABLE Input（推荐）`，“对方声音来源”第一项是 `扬声器回采：系统默认扬声器（推荐）`
- [ ] 把“送进会议”改成耳机：弹出提示“仅自己能听到 / 会造成回声”，卡片底部出现红色或蓝色说明；改回后提示消失
- [ ] 点“测试链路”→“开始测试”：送进会议 ✅、对方声音 ✅、麦克风（按提示说话）✅、监听能听到提示音
- [ ] 点“会议软件设置”：四个标签页的麦克风都写的是 `CABLE Output (VB-Audio Virtual Cable)`

## 4. 真实会议（3 分钟）

- [ ] 会议软件麦克风选 `CABLE Output`，扬声器选耳机；镜声点“开始”
- [ ] 说一句中文：对方（或另一台设备入会）听到英文；对话列表这句后面显示“识别 · 翻译 · 发声 = 总计”
- [ ] 对方说英文：屏幕出现中文字幕条
- [ ] 术语表加一行（如 `镜声, MirrorVoice, 静声`）并填会议背景，保存后说“静声”，原文显示为“镜声”、译文为 MirrorVoice
- [ ] “模型”改成“极速”，停止再开始：能下载 Qwen3-1.7B 并翻译（更快，质量略低）
- [ ] 按住右 Alt 说话 / Ctrl+Alt+M 静音生效

## 5. 更新（1 分钟，有新版本时）

- [ ] “检查更新”发现新版本 → 下载 → 静默安装后自动重新打开，模型和设置都在
- [ ] `%LOCALAPPDATA%\MirrorVoice\updates` 里不再留有安装包（下次启动清理）

出问题时附上：截图、`%LOCALAPPDATA%\MirrorVoice\debug.log`（翻译过程）和 `updates\update.log`（更新过程）。
